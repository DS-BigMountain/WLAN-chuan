# 传 · Android 应用

Android 应用用于局域网文件与文件夹收发，可独立提供设备发现和 Web 服务。当前版本：**V2.1.1**。

安装包及通用使用方法见[项目 README](../README.md)。运行需要 Android 8.0 及以上，以及可用的系统 WebView。

## 使用方法

1. 安装 APK 并打开应用，选择目标设备后发送文件或文件夹；也可从其他应用的系统分享菜单选择“传”。
2. 接收端可启用自动接收，或勾选申请项目后选择“接收”或“拒绝”。
3. 通过“接收目录 → 修改”授权保存目录；在应用中可浏览、打开或分享已接收文件。
4. 在“Web 服务”中复制访问地址，供同一局域网内的浏览器连接。

文件夹默认按原目录结构复制，可在发送设置中选择打包为 ZIP。任务列表提供进度、逐项结果、暂停、继续和重试操作。

应用打开后启动前台服务，进入后台后仍可收发文件。可从“Web 服务”或通知栏停止服务。

默认接收位置为应用专属目录，卸载应用会清除其中数据。需要长期保留的文件应保存至已授权的其他目录。删除接收记录会同时删除该任务实际接收的文件；“清除已结束”仅隐藏记录。
