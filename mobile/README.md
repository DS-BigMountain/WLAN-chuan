# 传 · Android 应用

Android 应用提供与 Windows 客户端一致的局域网文件传输协议，可独立承担发送端、接收端和 Web 服务主机。当前版本为 **V2.1.0**，最低运行环境为 Android 8.0，界面依赖已更新的系统 WebView。

## 功能与运行方式

应用支持 IPv4 局域网发现、手动连接、文件与文件夹互传、批次整体或部分审批、自动接收、数量及大小限制、传输进度与速率、取消和删除、Ping、IP 临时备注，以及接收文件的打开和分享。系统分享菜单中的“传”可接收其他应用提交的文件。

主界面上方选择目标设备并发送文件，接收申请在当前页按发送人分组展开，新到项目默认勾选。“全选”切换所有发送人的待处理项目，“接收”和“拒绝”仅处理勾选项；未勾选项目保留至后续处理。“本次传输”列表统一展示任务，使用全部、发送、接收筛选；点击文件夹任务名称可在原记录下展开逐项状态。

连接保持正常时，接收审批持续等待用户处理，发送端显示“等待对方确认”。发送任务被拒绝、取消或因网络问题失败后，可通过“重试”重新提交审批；文件夹按完整批次重新发送。

文件夹在接收方确认后，先打包为不压缩的 ZIP64，再作为单个文件整体发送。打包与传输分别显示进度，接收端验证完整后保存 ZIP，解压后恢复目录结构。源文件不可读时停止打包并显示具体路径；普通文件直接发送。

打开应用后自动启动通知栏可见的前台服务。服务独立运行，界面进入后台后仍可提供文件收发、设备发现、Web 中转与客户端安装包下载。可在主界面底部“Web 服务”或通知栏停止服务。服务运行期间保持 CPU 唤醒和组播接收。

默认接收位置为应用专属目录。通过主界面底部“接收目录 → 修改”选择系统目录后，应用保留系统授予的读写权限，传输完成并验证后再向该目录提交文件。接收目录可在应用中独立浏览，文件在服务重启或清除记录后仍可打开和分享。无需授予全盘文件访问权限。Android 卸载应用时会清除应用专属数据。

## Web 服务与多主机

默认使用 TCP `45871` 和 UDP `45872`。其他设备连接相同局域网后，可使用应用内复制的 Web 地址。

Web 页面与 Windows 端共用根目录 `src/web/` 中的资源。浏览器身份、偏好设置、请求令牌和下载凭据按服务主机隔离；每次服务启动建立新的运行会话。跨主机浏览器设备通过所属主机进行路由，目标浏览器负责自己的接收审批。主机身份或运行会话变化时，旧页面停止请求，需重新连接后提交传输。

浏览器的目录选择与写入受浏览器能力限制；Android 应用通过系统文件选择器处理目录。Windows 与 Android 原生协议在流式传输中计算并验证 SHA-256。网页上传采用原文件、长度及写入检查，主机之间转发时使用原生校验协议。

## 构建与安装

构建需要 JDK 17 或更高版本、Android SDK Platform 35、Build Tools 35.0.0，以及已构建的同版本 Windows 可执行文件。无需 Gradle、AndroidX 或 NDK。

在项目根目录执行：

```powershell
.\mobile\build.ps1 -AndroidSdk "C:\Android\Sdk"
```

默认读取 `build/v2.1/Release/Chuan.exe`，以便 Android 服务向浏览器提供 Windows 客户端下载。也可使用 `-DesktopExe` 指定绝对路径；该参数的相对路径以 `mobile/` 为基准。

APK 输出至 `mobile/build/outputs/Chuan-2.1-android.apk`。脚本验证 APK v2/v3 签名和 ZIP 对齐，构建中间文件位于系统临时目录。APK 不包含特定 CPU 架构的原生库。

发布签名密钥和密码保存在 `mobile/.signing/`，不进入 Git 或交付包。该目录应作为构建凭据保留，源码不包含密码。

统一生成桌面端与手机端交付目录：

```powershell
.\tools\package.ps1 -BuildDirectory ".\build\v2.1" -AndroidApk ".\mobile\build\outputs\Chuan-2.1-android.apk" -AndroidSdk "C:\Android\Sdk"
```

桌面程序通过同目录的 `Chuan-2.1-android.apk` 提供 Web 页面中的“Android 客户端”下载。Android 服务直接提供当前已安装的 APK。

## 源码结构

| 目录或文件 | 职责 |
| --- | --- |
| `src/main/java/local/chuan/core/` | 设备发现、HTTP、批次审批、文件传输、浏览器会话和多主机路由 |
| `src/main/java/local/chuan/app/` | Activity、前台服务、系统文件选择、持久目录授权和文件分享 |
| `src/main/assets/native/` | Android 应用界面，与共用 Web 样式及原图标配合 |
| `src/main/res/` | Android 主题和通知资源；启动图标从项目原图复制 |
| `build.ps1` | SDK 工具构建、签名和验证 |
| `tests/interop.mjs` | Java 核心、Windows 程序与 Chromium 的定向互操作验证 |
| `tests/HostMain.java` | 无 Android 依赖的协议验证宿主 |

局域网传输使用明文 TCP，适用于可信网络。服务端不提供账号认证或公网中继。原生接收端保留可续传数据，并在恢复前核验已接收前缀的 SHA-256。
