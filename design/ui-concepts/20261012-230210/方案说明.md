# 传：桌面界面设计方案

本组设计以当前 Windows 桌面客户端及其局域网 Web 服务为功能依据。各方案覆盖在线设备发现、目标设备选择、文件与文件夹发送、批次接收审批、传输状态、接收目录和浏览器接入。

## 方案比较

| 方案 | 适用场景 | 信息结构 |
| --- | --- | --- |
| A：快速传输工作台 | 日常少量项目交换 | 设备侧栏、发送区、审批提示和本次传输列表 |
| B：批次审批工作台 | 多项目批次发送与人工接收审批 | 紧凑发送工具栏、任务表格和固定审批面板 |
| C：设备会话与 Web 接入 | Windows 与手机浏览器互传、长时间运行 | 按设备组织传输、发送操作区和 Web 接入面板 |

## 功能约束

接收审批以顶层项目为单位，文件夹保持整体选择。示例采用关闭自动接收的状态，使待确认请求与设置一致。任务记录对应本次运行期间的状态。Web 服务展示现有访问地址、复制地址和打开网页操作。

## 已选方案

用户已选定 A：快速传输工作台。桌面界面采用该方案的信息结构，标志与控件图标沿用现有资源及绘制样式。B 与 C 保留为对照方案。

## 生成方式与提示词

图像使用内置 ImageGen 生成。完整提示词及每版参数记录于同目录的 generation-prompts.json。
