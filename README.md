# 传（Chuan）

传用于同一局域网内的文件与文件夹传输，提供 Windows 客户端、Android 应用和浏览器访问入口，无需部署独立服务器。

当前版本：**V2.3.0**。安装包与便携包见 [GitHub Releases](https://github.com/DS-BigMountain/WLAN-chuan/releases)。

## 主要功能

- 自动发现局域网设备，支持通过 IP 地址手动连接。
- 单文件、多文件及文件夹传输，支持拖放发送和 Android 系统分享。
- 文件夹按原目录结构复制，跳过内容相同的文件；可选择打包为 ZIP 发送。
- 自动接收或按项目审批，支持暂停、继续、失败重试及原生客户端断点续传。
- 查看传输进度、速率和逐项结果；Windows 支持增量导出及清除服务端诊断日志。
- Windows 与 Android 均可提供 Web 服务，供其他设备通过浏览器收发文件；Windows 支持显示访问地址二维码。
- Windows 与 Android 可在设置中检查并下载 GitHub 正式版本；Windows 重启后替换程序，Android 通过系统安装界面完成更新。

## 运行条件

- Windows 10/11 x64，或 Android 8.0 及以上；Android 需可用的系统 WebView。
- 设备处于同一 IPv4 局域网，接收目录具有写入权限及足够空间。
- 防火墙允许程序通信；默认使用 TCP `45871` 和 UDP `45872`。

## 使用方法

1. Windows 解压便携包后运行 `Chuan.exe`；Android 安装 APK 后打开应用。
2. 在设备列表选择目标设备。未自动发现时，使用“手动连接”输入对方 IP 地址和端口。
3. 选择文件或文件夹发送；Windows 也可拖放文件，Android 可从系统分享菜单选择“传”。
4. 接收端默认自动接收。关闭自动接收后，勾选待处理项目并选择“接收”或“拒绝”。
5. 在“接收目录”中查看或修改保存位置，在“本次传输”中查看结果及处理失败任务。

Windows 默认接收目录为 `%USERPROFILE%\Downloads\传`。Android 默认使用应用专属目录，也可授权其他目录；卸载应用会清除应用专属数据。

文件夹复制遇到同名且内容不同的文件时，会保留原文件并报告冲突；普通文件和 ZIP 使用编号避免覆盖。中断后重新选择同一文件夹并发送到原位置，可核对并补传缺失内容。需要接收 ZIP 时，在发送设置中开启“发送文件夹时打包为 ZIP”。

## 浏览器访问

在 Windows 或 Android 客户端中打开“Web 服务”，使用同一局域网内的浏览器访问显示的地址，例如 `http://192.168.1.10:45871/`。传输期间保持服务主机运行及浏览器页面开启。

浏览器的文件夹选择和接收能力受系统及浏览器接口限制。无法直接接收目录时，可使用原生客户端，或将文件夹打包为 ZIP 后下载。普通下载的保存结果需在浏览器下载列表中确认。

本项目使用明文局域网通信，不提供账号认证或公网穿透，应在可信网络中使用。
