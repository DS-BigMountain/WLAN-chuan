# 传（Chuan）

一款面向 Windows 的轻量级局域网文件传输工具。

**传（Chuan）** 用于在同一局域网内的设备之间快速传输文件与文件夹，提供 Windows 原生桌面客户端以及内置 Web 访问能力。程序无需部署独立服务器，也不依赖 Node.js、Python 等运行环境，可通过局域网自动发现设备或手动指定 IP 地址建立连接。

当前版本：**v1.0.0**

## 功能特性

- **局域网设备自动发现**
  - 自动发现同一 IPv4 局域网内运行 Chuan 的设备
  - 支持设备在线状态检测
  - 支持通过 IPv4 地址和端口手动连接
- **文件与文件夹传输**
  - 支持单文件及多文件批量发送
  - 支持非空文件夹传输
  - 文件夹保持原始目录结构，不转换为 ZIP
  - 支持 Unicode 文件名
  - 同名文件自动添加编号，避免覆盖已有文件
- **批次传输与接收审批**
  - 一次选择的多个项目以批次形式提交
  - 支持全部接受或仅接受部分项目
  - 文件夹作为不可拆分的整体接受或拒绝
  - 支持自动接收模式
  - 可分别限制单批文件数量和单批数据大小
- **Windows 原生客户端**
  - 原生 Win32 桌面程序
  - 提供设备列表、传输任务、进度、速率及结果状态
  - 支持拖放发送
  - 支持快速打开文件所在目录
  - 支持取消任务及清理已结束任务
- **内置 Web 服务**
  - 可通过手机、平板或其他电脑的浏览器访问
  - 无需额外部署 Web 服务
  - Web 资源直接嵌入可执行文件
  - 支持浏览器上传、下载、设备选择及 Ping
  - 不同浏览器实例拥有独立客户端身份
- **完整性校验**
  - 文件采用流式读写
  - 使用 SHA-256 进行完整性验证
  - 校验通过后才提交正式文件
  - 异常中断时自动清理未完成文件
- **Ping 与设备反馈**
  - 支持向指定设备发送 Ping
  - 桌面端和 Web 端均提供可视化反馈
  - 可用于快速确认设备是否处于可交互状态

## 系统要求

### 运行环境

- Windows 10 x64
- Windows 11 x64
- IPv4 局域网环境

程序为独立 Windows 可执行文件，不安装后台系统服务。

### 开发环境

从源码构建需要：

- Visual Studio C++ 桌面开发工具
- Windows SDK
- CMake 3.24 或更高版本
- 支持 C++20 的 MSVC 工具链
- Python（运行部分集成测试时需要）
- Node.js（运行 Web 测试时需要）

## 快速开始

### 1. 启动程序

在需要进行文件传输的 Windows 设备上运行：

```
Chuan.exe
```

程序启动后会自动广播设备信息，并持续检测局域网内其他在线设备。

### 2. 选择目标设备

在设备列表中选择需要发送文件的目标设备。

如果网络环境限制了 UDP 广播，可以使用“手动连接”功能输入目标设备的：

```
IPv4 地址
TCP 端口
```

建立直接连接。

### 3. 发送文件

选择目标设备后，可以：

- 将文件拖入发送区域；
- 选择一个或多个文件；
- 选择非空文件夹。

对于批量发送任务，接收端会收到完整项目清单，并根据接收设置决定是否接受。

### 4. 接收文件

默认情况下程序启用自动接收。

默认保存位置：

```
%USERPROFILE%\Downloads\传
```

关闭自动接收后，接收端需要手动确认传输请求。

对于包含多个项目的批次，可以：

- 全部接受；
- 仅接受指定项目；
- 拒绝整个批次。

已有同名文件不会被直接覆盖，程序会自动为新文件添加编号。

## Web 访问

Windows 客户端可以同时提供局域网 Web 服务。

在程序中打开“Web服务”后，会显示类似以下地址：

```
http://192.168.1.10:45871/
```

在与服务主机处于同一局域网的设备上，通过浏览器访问该地址即可使用 Web 客户端。

Web 客户端支持：

- 查看在线设备
- 选择目标设备
- 上传文件
- 上传文件夹（取决于浏览器能力）
- 接收文件
- Ping 设备
- 查看传输状态
- 设置临时设备备注
- 设置批次传输限制

无需安装额外 Web 服务，也不依赖外部网站。

### 浏览器文件夹支持

浏览器发送和接收文件夹的能力取决于浏览器及操作系统提供的文件系统接口。

部分移动端浏览器或 Android WebView 宿主可能无法正确提供目录选择能力。

如果浏览器不支持文件夹选择，可先将目录压缩为普通压缩文件后发送。

浏览器直接接收并恢复目录结构还需要浏览器支持目录写入接口以及安全上下文。无法满足这些条件时，建议使用 Windows 客户端完成文件夹接收。

## 网络说明

Chuan 默认使用以下端口：

| 类型 | 默认端口 | 用途                          |
| ---- | -------- | ----------------------------- |
| TCP  | `45871`  | 文件传输、设备通信及 Web 服务 |
| UDP  | `45872`  | 局域网设备发现                |

Windows 防火墙需要允许程序进行相应的局域网通信。

如果 UDP 广播不可用，可以通过“手动连接”直接连接对方 IPv4 地址。

### 网络范围

Chuan 主要面向：

```
可信 IPv4 局域网
```

当前版本不提供：

- NAT 穿透
- 公网中继服务
- 云端设备发现
- 互联网远程传输

## 传输机制

文件采用流式方式读取和写入，传输完成后执行 SHA-256 完整性验证。

典型流程如下：

```
发送请求
    ↓
接收端审批
    ↓
开始传输
    ↓
写入临时数据
    ↓
SHA-256 完整性验证
    ↓
提交正式文件
```

传输异常或连接中断时，未完成文件会被清理。

当前版本不支持断点续传，中断后的文件需要重新发送。

## 批次限制

桌面客户端和 Web 客户端均支持配置：

- 单批最大文件数量
- 单批最大总大小

默认值均为：

```
0
```

表示不设置业务层面的主动限制。

实际可传输规模仍然受到以下因素约束：

- 可用磁盘空间
- 可用系统内存
- 网络状况
- 文件系统限制
- 协议整数范围

## Web 中转

浏览器向其他设备发送文件时，文件会首先上传至当前 Web 服务主机的私有暂存目录，再由服务主机转发给最终接收设备。

流程如下：

```
浏览器
   ↓
Web 服务主机
   ↓
目标设备
```

最终目标设备仍然按照自己的接收策略决定是否接受文件。

暂存数据会在任务结束后一段时间自动清理，程序正常退出时也会执行清理。

## 安全说明

Chuan 的设计目标是方便可信局域网内部的设备之间快速传输文件，而不是作为互联网文件传输协议使用。

### 当前安全边界

文件传输使用普通 TCP 连接。

当前版本：

- **不提供传输层加密**
- **不提供用户账号认证**
- **不提供公网安全接入能力**

Web 客户端使用随机身份和请求令牌进行会话归属与部分跨站请求限制，但这些机制不能替代正式的身份认证或加密协议。

因此，请仅在可信局域网环境中使用 Chuan。

对于公共 Wi-Fi、酒店网络、校园公共网络或其他不可信网络环境，应谨慎启用文件接收及 Web 服务。

## 配置文件

桌面客户端设置保存在：

```
%LOCALAPPDATA%\Chuan\settings.ini
```

程序退出后：

- 文件传输停止；
- 设备发现停止；
- Web 服务停止。

Chuan 不会安装常驻后台系统服务。

## 启动故障处理

### 接收目录或配置文件不可写

各版本默认共用 `%LOCALAPPDATA%\Chuan\settings.ini`。该文件记录的接收目录失效，或配置文件的写入权限发生变化，均可能影响多个历史版本；重新下载可执行文件不会重置这些设置。

本修复构建保持版本号 `1.0.0`，启动时实际检查接收目录的写入能力。原目录不可用时，程序尝试使用 `%LOCALAPPDATA%\Chuan\received`，并在启动提示中列出原路径、系统错误及替代路径。使用 `--data-dir` 时，备用目录为该配置目录下的 `received`。原目录及其中的文件保持原状；备用目录保存成功后，共用该配置的历史版本也会读取新路径。

默认用户配置目录下的备用目录也不可写时，程序继续尝试可执行文件旁的 `data\received`，并将配置保存到 `data\settings.ini`。该便携配置存在时，后续普通启动优先读取它；移动程序时应同时保留此 `data` 目录。显式指定 `--data-dir` 时不启用此回退。历史可执行文件没有自动便携回退功能，但可通过相同的 `--data-dir` 参数使用该目录。

需要运行历史版本时，可在该版本所在的可写目录中打开 PowerShell，执行以下命令初始化独立配置及接收目录：

```powershell
.\Chuan.exe --data-dir ".\data" --receive-dir ".\data\received"
```

后续使用 `.\Chuan.exe --data-dir ".\data"` 启动，即可保留在界面中修改的接收目录。历史 `0.4.0` 已验证可通过指定可写配置目录恢复启动。

配置保存失败时，程序显示具体路径和系统错误，并继续本次会话；部分设置可能无法在重启后保留。应检查 `settings.ini` 的只读属性、文件占用和用户写入权限。所有接收目录均不可写时，程序终止启动，并提供各失败路径。也可通过 `--receive-dir "D:\接收文件"` 指定可写目录，通过 `--data-dir "D:\Chuan配置"` 指定配置目录。

### Windows SmartScreen 提示

当前发行包未附加发行者数字签名，Windows SmartScreen 可能显示“Windows 已保护你的电脑”及“发布者未知”。该提示属于 Windows 的应用信任检查，与程序内部的目录访问错误分别发生。

对于已确认来自本项目可信构建的程序，可在该文件的 SmartScreen 提示中选择“更多信息”后选择“仍要运行”；截图已展开详细信息时，可直接选择“仍要运行”。无需关闭系统级 SmartScreen 或 Microsoft Defender。来源不明的副本应先重新获取可信构建。

面向外部分发时，需要使用受 Windows 信任的代码签名证书对最终可执行文件执行 Authenticode 签名并添加时间戳。有效签名用于验证发行者身份，但 SmartScreen 仍可能根据文件信誉或设备策略显示提示。修改版本资源或使用未受信任的自签名证书不能替代发行签名。

## 当前限制

- 仅面向 Windows 10 / Windows 11 x64 桌面客户端
- 仅支持 IPv4 局域网环境
- 不提供公网穿透
- 不提供端到端加密
- 不提供账号认证
- 不支持断点续传
- 不传输空文件夹
- 浏览器文件夹功能受浏览器和系统能力限制
- 浏览器无法证明下载内容最终是否已经保存到用户磁盘
- 部分 Android WebView 浏览器可能无法正确支持文件夹选择
- 当前构建未附加发行者数字签名

## 使用场景

Chuan 适用于需要在可信局域网中快速交换文件的场景，例如：

- Windows 电脑之间传输文件
- 手机向 Windows 电脑发送文件
- 无需登录账号的临时文件共享
- 无互联网环境下的局域网数据交换
- 开发、测试及实验室内部文件传输

> **安全提示**
>
> Chuan 当前使用明文 TCP 进行数据传输。请仅在你信任的局域网环境中使用，不建议直接暴露到公网。
